# Claims ledger

Every number or factual claim in the write-up, the README or the video gets a row here before it ships. A claim
that cannot be traced to a source or a logged run does not ship.

- **Market claims** need a source a judge can open, with its date.
- **Our measurements** need the run they came from: a row in [../field-notes.md](../field-notes.md), a script, or a test.
- Word each claim as narrowly as its evidence ("in our 12 sandbox runs", not "always").
- Sandbox runs are sandbox runs: say so.
